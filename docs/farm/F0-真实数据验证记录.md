# F0 真实数据验证记录

> 日期：2026-10-11
> 状态：技术字段与业务统一时间含义均已确认
> 操作边界：只读查询现有缓存和 COC 官方 API，未写生产数据库

## 1. 验证目的

验证互刷登记所依赖的官方 `currentwar` 数据是否能够稳定提供：

- 普通部落战状态；
- 本方和对手标签；
- `preparationStartTime`、`startTime` 和 `endTime`；
- 内部匹配双方一致的战争身份；
- 配置标签与官方标签的规范化差异。

## 2. 当前缓存概况

2026-10-11 查询 `current_war_cache` 时，8 个现有 `category=farm` 部落均为 `inWar`，缓存更新时间为
`2026-10-11T08:30:28+00:00`。其中缓存已经呈现两组双方均在现有互刷名单内的内部匹配：

| 本方 | 对手 | 结果 |
|---|---|---|

| `#U2UL` | `#R88U8` | 双方互为对手 |

| `#2JU` | `#YC0C` | 双方互为对手 |

其余 4 个部落的对手不在当前 8 个互刷部落中，可作为“匹配失败、积分不变”的测试样本。

## 3. 官方 API 双向验证

通过项目 `shared.config.env_loader.load_env()` 加载环境，并调用现有
`CocApiClient.get_current_war()`，未打印或记录 Token、授权头和原始成员数据。

### 3.1 `#R88U8` 与 `#U2UL`

双方返回完全相同的时间字段：

| 字段 | UTC | 北京时间 |
|---|---|---|
| `preparationStartTime` | `2026-10-10 03:11:39` | `2026-10-10 11:11:39` |
| `startTime` | `2026-10-11 02:11:39` | `2026-10-11 10:11:39` |
| `endTime` | `2026-10-12 02:11:39` | `2026-10-12 10:11:39` |

双方均返回：

- `state = inWar`；
- `attacksPerMember = 2`；
- `type` 未标记为 `cwl`；
- 本方和对手标签相互对应。

这组数据可以稳定识别为普通内部部落战。

### 3.2 配置 `#YCOC` 与 `#2JU`

双方同样返回一致时间：

| 字段 | UTC | 北京时间 |
|---|---|---|
| `preparationStartTime` | `2026-10-10 03:19:09` | `2026-10-10 11:19:09` |
| `startTime` | `2026-10-11 02:19:09` | `2026-10-11 10:19:09` |
| `endTime` | `2026-10-12 02:19:09` | `2026-10-12 10:19:09` |

关键差异：

- 请求和历史配置使用 `#YCOC`；
- COC 官方返回本方标签 `#YC0C`；
- 官方标签字符集中使用数字 `0`，游戏字体或历史录入容易写成字母 `O`。

因此互刷系统必须保存或生成唯一的 COC 比较键：

```text
去空格 → 转大写 → 补齐 # → O 替换为 0
```

内部匹配、唯一归属、场次快照和 API 权限比较都必须使用同一规范化函数，不能直接比较原始字符串。

## 4. 8 个部落的时间分布

当前样本的 `preparationStartTime` 分布在北京时间 `11:11:39–11:32:59`，跨度约 21 分钟；
`startTime` 分布在次日北京时间 `10:11:39–10:32:59`，跨度相同。

这说明：

- 各配对不是完全同秒匹配成功；
- 业务统一时间不能和每个部落的官方时间做精确相等比较；
- 必须使用可配置误差窗口；
- 运营已确认统一时间就是“开始搜战的时间”，因此固定使用 `preparationStartTime` 校验。

## 5. F0 结论

已确认：

1. 官方 `currentwar` 可以提供稳定的本方和对手标签；
2. 内部匹配双方返回的三个时间字段完全一致；
3. `state` 与 `attacksPerMember` 足以辅助排除 CWL；
4. 当前样本同时覆盖内部匹配和非内部对手；
5. 标签必须额外执行 `O → 0` 的 COC 比较归一化；
6. 时间判断必须允许误差窗口，不能精确相等；
7. 官方调用失败必须与 `notInWar`、时间不符和匹配失败分开；
8. 业务统一时间固定为“开始搜战的时间”，映射到官方 `preparationStartTime`。

第一版误差窗口采用 2700 秒（45 分钟），覆盖当前样本约 21 分钟的实际匹配跨度并保留安全余量。
该值由 `FARM_SYSTEM_TIME_TOLERANCE_SECONDS` 集中配置，限制在 60–7200 秒；真实灰度后再根据登记记录评估是否收紧。
