# 部落主页概览与内嵌子页

## 1. 目标与页面层级

`pages/clan/clan` 是原生 TabBar 的“部落”主页。顶部固定四个功能入口：

```
部落                         🏠概览  👥成员  ⚔️战营  🔄互刷
--------------------------------------------------------
                         当前内容
--------------------------------------------------------
              部落  战斗  账号  设置（原生 TabBar）
```

- 普通进入“部落”时默认为“概览”。
- 四个功能和单部落详情都在该 Tab 页内切换，不使用 `navigateTo`，不会隐藏底部 TabBar。
- 小程序重启或普通入口的默认页仍是“战斗 → 部落战”，因为 `pages/war/war` 仍是 `pages.json` 首页。
- 选中入口使用蓝色文字/图标和浅蓝背景，整个按钮区域可点击。

## 2. 概览卡片

概览按 `config/settings.yaml` 中已启用自有部落的配置顺序展示，当前目标为 12 个卡片。每张卡片包含：

- 部落名称、标签和类别（战营 / 混营实战 / 偷矿 / 互刷）；
- 当前成员数 `/50`、平均大本、人均奖杯、首领；
- 当前赛季捐兵总数和最后同步时间；
- 四项数据下方显示两项轻量运营状态：部落战和都城突袭；
- 整张卡片点击进入单部落详情。

状态行不使用独立底色或按钮，只用蓝色和灰色表达状态：部落战的准备日、战斗日和联赛中为蓝色，无战争、已结束和状态未知为灰色；都城突袭中和未到时间为蓝色，未开启和状态未知为灰色。突袭周末结束后，底层保存的已结束或本周未开启在卡片上统一显示为下一周的“未到时间”。类别标签和详情入口保留蓝色高亮，不再使用红、黄、绿色。

某个部落没有成员快照时显示“等待首次同步”和空聚合，其他部落不受影响。概览不展示当前战争、排名或个人捐兵榜。

## 3. 单部落详情

详情仍在 `pages/clan/clan` 内展示，顶部“概览”保持选中，内容区提供大尺寸“返回部落概览”。内容包含：

- 顶部官方资料：徽章、等级、官方名称、标签、内部类别、官方成员数和加入方式；
- 战争资料：胜/平/负、当前连胜、部落战联赛和开战频率；
- 积分与基础资料：部落奖杯、夜世界奖杯、都城奖杯、都城联赛、地区、加入门槛、战争日志可见性、家庭友好、官方标签和描述；
- 成员聚合：首领、平均大本、人均奖杯、大本等级分布和职位分布；
- 大本等级分布和职位分布；
- 捐兵汇总：总捐出、总收到、人均捐出；
- 快捷入口：所有部落都可按该部落预筛选成员；仅云深不知处战营（`#2QQ`）显示“查看战营数据”；互刷部落显示“查看互刷数据”；其他实战和偷矿部落不显示额外数据入口。

详情不再重复显示完整成员宽表。

## 4. 数据边界与加载

- `GET /api/clan/overview` 返回概览卡片；`GET /api/clan/overview/{clan_tag}` 返回单部落聚合详情。
- 两个接口只读现有 `accounts` 快照、`coc_raw` 捐兵字段、`clan_profile_cache`、`current_war_cache` 和 `capital_raid_status_cache`，请求路径不访问 COC API。
- `clan_profile_cache` 保存 12 个已启用自有部落的规范化官方资料，跟随 `coc_sync` 每 6 小时更新；失败时保留上次成功值并在页面标记为旧缓存。
- `capital_raid_status` 每 10 分钟检查一次：突袭周末中仅继续查询尚未开启或失败的部落，检测到已开启后停止重复拉取；周末结束后收口为“已结束”或“本周未开启”。
- 官方徽章来自 `https://api-assets.clashofclans.com`，页面已提供加载失败占位。真机若只显示占位，需在微信公众平台将该域名加入图片下载合法域名。
- 只统计 `membership_status = 'member'` 且当前 `clan_tag` 命中已启用自有部落的账号。
- 概览默认加载；成员、战营、互刷只在首次点击时加载。概览先显示模块内缓存，并在重新进入部落 Tab 或从其他子页返回时后台刷新本地 API，确保运营状态不会长期停留在旧值；大型表格仍不保留隐藏 DOM。

## 5. 分享和旧路由

分享统一使用 `pages/clan/clan`：

- 概览：`/pages/clan/clan?section=overview`
- 成员：`/pages/clan/clan?section=members`
- 战营：`/pages/clan/clan?section=stats`
- 互刷：`/pages/clan/clan?section=farm`
- 单部落：`/pages/clan/clan?section=clan-detail&clan_tag=...`

旧路由 `pages/clan/detail`、`pages/clan/stats`、`pages/clan/farm` 从 `pages.json` 移除，不提供重定向或历史分享兼容。
